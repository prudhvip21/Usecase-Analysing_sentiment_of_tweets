# Analysing Sentiment of Tweets

Collect tweets on a topic and analyse the sentiment expressed in them.

## Approach

- Tweet collection through the Twitter API with Tweepy, both streaming and non-streaming
- Text cleaning with NLTK
- Sentiment analysis and visualisation

## Start here

[TwitterSentimentAnalysis.ipynb](TwitterSentimentAnalysis.ipynb)

## Data

Add your own Twitter API credentials in place of the placeholders in the notebook.
